# CS-4: original trilogy actor and inventory reader

`XRayTrilogyReader` reads the original Shadow of Chernobyl, Clear Sky, and Call
of Pripyat formats from content: outer and ALIFE versions must match the
supported original-game family, and the actor spawn version must match that
family. Enhanced Edition ALIFE versions are rejected by this reader.

`XRayEnhancedReader` accepts the Enhanced Edition ALIFE versions: SoC EE uses
outer 3 / ALIFE 51; CS EE and CoP EE use outer 6 / ALIFE 54. The latter pair is
distinguished by the case-sensitive `marsh` and `zaton` markers in the OBJECT
chunk. It rejects saves with neither marker or with both markers. Both readers
use the same read-only actor and inventory model.

The parsed view includes actor money, health, faction index, rank, reputation,
name, game time, and actor-owned object records. Ammo counts are exposed only
when both the known STATE and UPDATE fields parse. Other inventory fields stay
unknown/read-only; a section name does not authorize inventing a count or
serializer data.

The SoC, CS, and CoP readers also expose the actor's saved community-goodwill
rows from ALIFE chunk 9. The parser stops after the character relation map and
leaves malformed or incomplete registries read-only. The original releases
support experimental player-faction and goodwill edits through the shared
EditPlan; CS EE and CoP EE relation/faction values are readable, while writes
remain unsupported by the Python capability registry.

Tests use byte fixtures generated by `tools/generate_fixtures.py` from the
Python oracle's synthetic `_fixture` helpers. The golden subset for actor,
inventory, and time is exported by the Python oracle's `tools/export_golden.py`.
No personal saves or user paths are included.
