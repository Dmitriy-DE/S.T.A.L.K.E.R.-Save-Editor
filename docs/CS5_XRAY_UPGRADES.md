# CS-5: X-Ray item upgrades

`XRayUpgradeWriter` reads and writes the serialized upgrade vector for actor
inventory items in Clear Sky and Call of Pripyat, including their Enhanced
Edition saves. It accepts an item handle and an ordered list of upgrade keys in
`EditPlan.Upgrades`; the shared `XRayEditWriter` routes these edits through the
same core path as the other supported X-Ray mutations.

Before writing, the writer checks the source SHA-256, confirms that the target
object belongs to the actor and has a versioned upgrade vector, and validates
new keys against the matching release catalog and item type. A key already
present in the save may be preserved even if it is absent from the current
catalog. This keeps legacy values intact while rejecting newly introduced
unknown or item-inapplicable keys. The vector is replaced in place within the
SPAWN record; state and packet size fields are adjusted, the UPDATE packet and
following STATE bytes are preserved, and the output is reparsed for round-trip
verification.

The synthetic vectors in `tests/Fixtures/writer-upgrades` are generated by
`tools/generate_xray_upgrades_fixtures.py` from the read-only Python oracle.
Tests compare the compressed save and unpacked X-Ray bytes for Clear Sky,
Call of Pripyat, and both Enhanced Edition formats. They also reject unknown
keys, keys for another item, foreign catalogs, unknown handles, and formats
without a supported upgrade vector. These vectors verify serialization parity;
the edits have not been verified by loading and saving them in the games.
