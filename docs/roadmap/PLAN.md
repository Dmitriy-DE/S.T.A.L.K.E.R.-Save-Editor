# План переезда на C#: от текущего состояния до релиза 1.0 и дальше

Цель — C#-версия умеет всё то же, что Python 0.7.6. Затем она выходит как 1.0, а Python уходит в архив. Моды, Workshop и телепорт — сразу после 1.0.

## Где мы (27.09)

В `main` C#-репозитория уже есть:
- чтение всех 7 форматов;
- деньги трилогии и EE;
- стаки трилогии и EE;
- удаление и добавление предметов в трилогии и EE;
- чтение Steam;
- окно Avalonia;
- замеры скорости в CI.

Тестами покрыто 90 из 162 сценариев Python (таблица `out/PARITY2.csv`).

## Правила

- Каждый PR проходит ревью Claude: локальный `dotnet test`, сверка с Python, зелёный CI. Codex и Gemini сами PR не вливают.
- Запись только после паритета с Python по байтам. Чего нет в Python, то только чтение, пока владелец не проверит в игре.
- Веб-версия остаётся Python-сборкой до отдельного решения.
