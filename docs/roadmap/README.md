### До какого уровня проверено

- **L2:** 1108 тестов (Core 992, Steam 76, CLI 40), сборка без предупреждений, CI на Windows, Linux и macOS, отдельная
  проверка Lua компаньона, проверка 14 переводов и звуков.
- **L3:** CI запускает собранное приложение; Linux-пакет и CLI проверялись руками. Установщик Windows и пакет macOS на
  железе не запускались.
- **L4:** обновление на Linux (dpkg) у владельца; компаньон в ЗП у владельца; чтение всех локальных сейвов владельца
  командами `info` и `inventory` (читаются все).
- **L5:** нет ни одного подтверждения для C#-версии. (У Python-версии были: деньги ЧН EE и ЗП EE, стаки S2.)
- **Фиксы:** каждый патч проверен по дампам шести игр (`tools/fix_regress.py`), каждый фикс ставится и снимается на
  копиях шести реальных установок (`tools/fix_realcheck.sh`), логика одного фикса исполнена вне игры
  (`tools/lua_harness`). В играх не запускалось ничего.

### Известные ограничения

- Сохранение ЧН/ЗП, записанное редактором, примерно в 4 раза больше исходного (другой уровень сжатия); игра такие
  читает по формату, в игре не проверено.
- Горячие клавиши на Linux требуют X11 или XWayland.
- Публикация выпуска на R2 и в APT выполняется вручную: секретов в GitHub нет.
