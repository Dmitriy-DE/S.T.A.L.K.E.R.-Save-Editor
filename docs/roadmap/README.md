# Roadmap: что сделано, что осталось

Живой трекер. Состояние на 2026-10-02 (после v1.2.0, каталог фиксов 2026.10.1).

- [STATE.md](STATE.md) — что есть в программе и до какого уровня это проверено.

- [FIX-PACKS.md](FIX-PACKS.md) — фиксы игр: источники, что не взято и почему.
- [FIX-AUDIT-2026-10-02.md](FIX-AUDIT-2026-10-02.md) — запись по каждому фиксу и регрессия всего каталога.

- [DECISIONS.md](DECISIONS.md), [LESSONS.md](LESSONS.md) — решения владельца и ошибки, которые нельзя повторять.
