## 5. Что сломает 1.0 у текущих пользователей (блокеры)

1. **Имя пакета.** Python ставился как `.deb` `stalker2-save-editor` и Inno `AppId {B5B1C7A0-…}`. C# собирается как `stalker-save-editor` и `AppId {5E973B9B-…}`. OTA с 0.7.6 поставит C# рядом со старой версией, а не вместо. Нужно взять имена и AppId Python или объявить `Replaces/Conflicts` и удаление старого.
2. **Данные пользователя.** Python хранит настройки, бэкапы и журнал в `~/.local/share/Stalker2SaveEditor` (Windows: `%APPDATA%\Stalker2SaveEditor`), C# — в `StalkerSaveEditor`. Нужен одноразовый импорт при первом запуске (копия, оригинал не трогать).
3. **Релизный конвейер.** Схема манифеста у C# `UpdateService` совпадает с Python (проверено: те же поля) — это хорошо. Но инструмента, который собирает манифест, считает SHA, грузит на R2 и обновляет APT, в C# нет.
4. **Установщик мода на ТЧ/ЧН падает** (проверено на реальных установках 28.09) — бриф Codex выдан.
5. **Ни одна запись C# не проверена в игре (L5).** Писатели сделаны байт-в-байт с Python, но переходы, размещение, фракции и прочность и в Python не имели L5.

## 6. Какие версии будут и как это работает

| Сборка | Что внутри | Как ставится и обновляется |
|---|---|---|
| Приложение Windows x64 | Avalonia + Core + CLI | Установщик Inno (тот же AppId, что у Python) и portable zip; OTA по манифесту |
| Приложение Linux x64 | то же | `.deb` из APT-репо (старый ключ) и AppImage; OTA — `pkexec apt` |
| Приложение macOS arm64/x64 | то же | `.dmg`, ad-hoc; обновление «скачать и заменить» |
| Мод-компаньон ТЧ/ЧН/ЗП | Lua + xml + ltx + dds | ставит приложение (вкладка «Компаньон»), плюс zip на каждую игру для ручной установки |
| Компаньон EE | то же, упакованное под Workshop | Workshop (публикует владелец) |
| Веб | **решение владельца**: (а) оставить Python-веб замороженным как есть; (б) убрать вместе с Python; (в) отдельный spike C# в WebAssembly (Kraken — нативный, для S2 его нужно собрать через Emscripten) | — |

Работа: приложение правит сейвы офлайн (всегда с бэкапом и проверкой обратным чтением), облако — через дочерний процесс с `libsteam_api`, мод — по файловому протоколу v1, хоткеи ловит приложение и шлёт команду моду.

## 7. Лёгкий установщик и докачка

Сейчас AppImage 43 МБ, `.deb` 42 МБ. Из них ≈35 МБ — среда .NET, Avalonia и Skia. Своего содержимого ≈5 МБ. С иконками (9 МБ) и музыкой (9 МБ) будет ≈60 МБ.

Варианты:
- **А. Один полный пакет** — работает офлайн, проще всего. Рекомендация для 1.0.
- **Б. Базовый пакет + пакеты контента по играм.** Приложение при первом запуске (или при выборе игры) докачивает иконки и музыку нужной игры с R2 по манифесту: SHA-256 и подпись, кэш с версией, офлайн — приложение работает без картинок и музыки. Плюс: каталоги и иконки можно обновлять без релиза приложения. Рекомендация для 1.1.
- **В. Крошечный загрузчик, который скачивает само приложение.** Выигрыш — пара десятков МБ, взамен лишняя точка отказа и предупреждения SmartScreen. На Linux и macOS смысла нет. Не рекомендую.

Отдельно размер можно снизить сборкой Desktop через NativeAOT (Avalonia поддерживает) — это часть E4.

  - EE — отдельные игры: ставить через Workshop, не в `gamedata`;
  - предупреждение о сторонних модах в `gamedata` (у владельца в ЧН стоит OGSM).
- Интерфейс: в мастере первого запуска и на вкладке «Компаньон» — список найденных игр с галочками («ТЧ — Steam, путь…», «ЧН — Steam, найден OGSM», «ЗП»), кнопка «Поставить в отмеченные», у каждой игры статус, версия мода, «Обновить» и «Удалить».
- Ставить из приложения, а не из системного установщика: одинаково на трёх ОС, мод обновляется вместе с приложением, удаление по манифесту. Для тех, у кого нет приложения, — zip мода на каждую игру и маленький CLI-установщик (NativeAOT, один файл).
- Версия мода должна приходить в ответе на `ping`, чтобы приложение предлагало обновить мод после своего обновления.
