# Synthetic golden vectors

`fixture-vectors.json` is generated by the Python repository's
`tools/export_golden.py` using only the synthetic `.sav` files produced by
`tools/generate_fixtures.py`. It contains no personal save data or file paths.

Regenerate it together with the codec fixtures:

```bash
python tools/generate_fixtures.py --python-repo /path/to/S.T.A.L.K.E.R.-Save_Editor
```
