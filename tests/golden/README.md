# Synthetic golden vectors

This directory contains verified golden test vectors generated from the Python oracle (`save-editor`) using only synthetic save files. It contains no personal save data or user-specific paths.

## Master reader vectors

- `fixture-vectors.json`: generated by Python `tools/export_golden.py` using synthetic saves from `tools/generate_fixtures.py`. Covers base reader invariants for SoC, CS, CoP, SoC EE, CS EE, CoP EE, and S2.

## P2 Writer vectors

### 1. Durability (`xray-durability-vectors.json` / `Fixtures/writer-durability`)
Generated by `tools/generate_xray_durability_fixtures.py` using `editor/xray_item_state.py` and `tests/test_xray_durability.py`.
- **Target formats**: `stalker-soc`, `stalker-cs`, `stalker-cop`, `stalker-soc-ee`, `stalker-cs-ee`, `stalker-cop-ee`.
- **Vector fields**:
  - `releaseId`: format identifier (e.g. `stalker-cop`).
  - `source`, `expected`, `expectedRaw`: filenames in `Fixtures/writer-durability/`.
  - `sourceSha256`, `expectedSha256`, `expectedRawSha256`: SHA256 checksums before and after modification.
  - `handle`: 32-bit item handle (`0x3456`).
  - `sourceCondition`: initial float condition (`0.25`).
  - `targetCondition`: written float condition (`0.75`).
  - `changedRawOffsets`: exact 0-indexed byte offsets in the uncompressed container payload modified by writer.
  - `capabilities`: maturity matrix for this format.
- **Negative cases**:
  - `outOfRangeCondition`: condition > 1.0 or < 0.0 rejected by `EditPlan` (`ValueError`).
  - `unknownItemHandle`: handle `0x9999` rejected (`XRaySaveError`).
  - `staleSourceSha`: save modified externally rejected before write.

### 2. Upgrades (`xray-upgrades-vectors.json` / `Fixtures/writer-upgrades`)
Generated by `tools/generate_xray_upgrades_fixtures.py` using `tests/test_xray_upgrades.py`.
- **Target formats**: `stalker-cs`, `stalker-cop`, `stalker-cs-ee`, `stalker-cop-ee`.
- **Vector fields**:
  - `releaseId`: format identifier.
  - `source`, `expected`, `expectedRaw`: filenames in `Fixtures/writer-upgrades/`.
  - `sourceSha256`, `expectedSha256`, `expectedRawSha256`: SHA256 checksums before and after.
  - `handle`: item handle (`0x3456`).
  - `sourceUpgrades`: initial upgrades tuple (`["up_a_wpn_test", "legacy_unknown"]`).
  - `targetUpgrades`: written upgrades tuple (`["legacy_unknown", "up_c_wpn_test"]`).
  - `changedRawOffsets`: byte offsets modified in the uncompressed container payload.
- **Negative cases**:
  - `unregisteredUpgradeKey`: upgrade key not present in release catalog rejected (`XRaySaveError`).
  - `unsupportedReleaseSoc`: `stalker-soc` does not have upgrades vector and rejects upgrades edits (`XRaySaveError`).
  - `unknownItemHandle`: unknown item handle rejected.

### 3. Placement (`xray-placement-vectors.json` / `Fixtures/writer-placement`)
Generated by `tools/generate_xray_placement_fixtures.py` using `tests/test_xray_placement.py`.
- **Target formats**: `stalker-soc`, `stalker-cs`, `stalker-cop`, `stalker-soc-ee`, `stalker-cs-ee`, `stalker-cop-ee`.
- **Vector fields**:
  - `releaseId`: format identifier.
  - `source`, `expected`, `expectedRaw`: filenames in `Fixtures/writer-placement/`.
  - `sourceSha256`, `expectedSha256`, `expectedRawSha256`: SHA256 checksums before and after.
  - `handle`: item handle (`0x3456`).
  - `sourcePlacement`: initial location `{"type": "ruck", "slot": 2, "baseSlot": 3, "storage": "inventory"}`.
  - `targetPlacement`: moved location `{"type": "slot", "slot": 3, "baseSlot": 3, "storage": "equipped"}`.
  - `changedRawOffsets`: byte offsets modified in the uncompressed container payload.
- **Negative cases**:
  - `inappropriateSlot`: weapon placed into slot 12 (helmet slot) rejected by game rules (`XRaySaveError`).
  - `inappropriateBelt`: weapon placed on belt rejected (belt is restricted to artifacts) (`XRaySaveError`).
  - `slotOutOfRange`: slot number outside 1..13 rejected by `EditPlan` (`ValueError`).
  - `unknownItemHandle`: unknown item handle rejected.

## Regeneration

Run from the repository root:

```bash
python tools/generate_xray_durability_fixtures.py --python-repo /path/to/S.T.A.L.K.E.R.-Save_Editor
python tools/generate_xray_upgrades_fixtures.py --python-repo /path/to/S.T.A.L.K.E.R.-Save_Editor
python tools/generate_xray_placement_fixtures.py --python-repo /path/to/S.T.A.L.K.E.R.-Save_Editor
```

The add-writer vectors for clone reset and placement are regenerated with:

```bash
python tools/generate_xray_add_fixtures.py --python-repo /path/to/S.T.A.L.K.E.R.-Save_Editor
```

Steam parser and cloud transaction fixtures use the Python oracle as follows:

```bash
python tools/generate_steam_vdf_fixtures.py --python-repo /path/to/S.T.A.L.K.E.R.-Save_Editor
python /path/to/S.T.A.L.K.E.R.-Save_Editor/tools/build_ooz_encoder.py --root /path/to/S.T.A.L.K.E.R.-Save_Editor --output-dir /path/to/temporary/ooz-encoder
PYTHONPATH=/path/to/temporary/ooz-encoder python tools/generate_cloud_transaction_fixtures.py --python-repo /path/to/S.T.A.L.K.E.R.-Save_Editor
```

Capability metadata is generated by `tools/generate_capability_snapshot.py` from the same read-only Python oracle.
